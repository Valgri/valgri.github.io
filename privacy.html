Privacy policy

youtube-pipeline · last updated 10 October 2026

What the app accesses

With the account owner's consent, youtube-pipeline requests two read-only Google scopes: youtube.readonly (channel and video details) and yt-analytics.readonly (views, watch time, audience retention). It cannot upload, change or delete anything on a channel.

How the data is used

The data is used only to analyse the author's own channels. It is processed and stored on the author's own computer, together with the sign-in token. Nothing is sent to any server other than Google's APIs, and nothing is sold, shared or used for advertising.

Google API Services User Data Policy

youtube-pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.
